# CODE — 本地交互原型

双击 `index.html` 在浏览器中打开。在 VS Code 里打开此文件夹，选择「Terminal → Run Task → Preview CODE」，浏览器访问 http://127.0.0.1:5500 。

- 开场是铺满视口的字符方格，五种编码随方格缓慢交错。鼠标进入画面中央时颗粒向外散开，细线和五张小图随之显现。向下滚轮放大，完全展开后悬停一张图可暂停全网并恢复该图颜色。点击进入章节。
- 在章节右侧的固定框内按住拖动，笔触经过的整行会显字。拖过固定标题可解码标题。笔迹随各自的文字区域移动，返回网络时清空。
- 键盘可用 + / − 放大缩小，Escape 返回网络或缩回开场。
- `assets/` 存放原图和像素颜色，`content/` 存放英文稿与来源。
